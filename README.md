# VS Code Image Converter 🍦

**Convertisseur d'images pour VS Code** est une extension pour Visual Studio Code qui vous permet de convertir rapidement des images dans différents formats directement depuis l'éditeur de code.

## Fonctionnalités

-   Convertissez facilement une ou plusieurs images à la fois dans divers formats.
-   Prend en charge les formats d'image suivants : PNG, JPG, JPEG, WEBP, TIFF, HEIC.
-   Utilisez-le directement depuis l'explorateur de fichiers ou via des commandes enregistrées.

## Utilisation

### Convertir une seule image

1. Sélectionnez l'image à convertir dans l'explorateur de fichiers.
2. Faites un clic droit sur l'image.
3. Choisissez l'option "Convertir l'image" dans le menu contextuel.
4. Sélectionnez le format de conversion dans la boîte de dialogue.
5. Appuyez sur Entrée pour confirmer.

### Convertir plusieurs images à la fois

1. Sélectionnez plusieurs images à convertir dans l'explorateur de fichiers.
2. Faites un clic droit sur les images sélectionnées.
3. Choisissez l'option "Convertir les images" dans le menu contextuel.
4. Sélectionnez le format de conversion dans la boîte de dialogue.
5. Appuyez sur Entrée pour confirmer.
